## Report

**Project summary (two sentences):**
`tally` is a tiny Node/TypeScript CLI that reads a text file and prints the sum of the numbers in it, one number per line. It splits the file into lines in `src/tally.ts`, delegates per-line parsing to `parseLine` in `src/parse.ts` (which skips blank lines and `#` comments), and accumulates the result.

**Bug / edge case in `src/parse.ts`:**
`Number.parseInt(text, 10)` accepts trailing garbage, so partially-numeric lines are silently truncated instead of rejected. `parseLine("12abc")` returns `12` rather than throwing, and `parseLine("3.7")` returns `3` and `parseLine("1e3")` returns `1` — the `Number.isNaN` guard only catches lines that are entirely non-numeric, so a typo'd or truncated number quietly contributes the wrong amount to the total rather than erroring. (Fix: use `Number(text)` plus `Number.isFinite`, or validate the whole line against a numeric regex before parsing.)
