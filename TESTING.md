# Testing Blackbox Receipts

`pnpm test` runs `node --test` over `test/*.test.ts` from source. No external API is mocked. Tests that
need a tool server start the real proxy over stdio with the MCP SDK client, and the `--upstream` tests put
it in front of `test/fixtures/upstream-server.mjs`, a small hand-written JSON-RPC MCP server with no SDK.
Tests that need git create real repositories in temp directories. Each test uses throwaway receipt and
key directories (`RECEIPTS_DIR`, `BLACKBOX_KEY_DIR`), so nothing touches `~/.blackbox`.

## Live runs (not part of `pnpm test`)

- `scripts/demo-agent.sh`: a real LLM agent (opencode 1.18.31, OpenRouter `minimax/minimax-m3.1-flash:free`) restricted to the proxy's tools, against `examples/injection-repo`. Three runs are committed under `receipts/agent-demo/` (README "Live agent run"): two from 2026-10-21 with the checklist prompt (minimax free, since removed from OpenRouter's free list), and one from 2026-10-22 with the neutral prompt (`openrouter/cohere/north-mini-code:free`). Since 2026-10-22 the script runs opencode with an empty `XDG_CONFIG_HOME`, sets `permission: {"*": "deny", "blackbox_*": "allow"}`, checks the resolved config before the run, and exports nothing if the transcript shows a tool call outside the proxy: a global opencode config with `"*": "allow"` had handed an earlier attempt opencode's own bash and read tools (that attempt recorded nothing and was not exported).
- `packages/proxy/dist/bench.js`: per-call overhead, 20 sessions × 25 calls, real measurements in `docs/benchmark.json` (about 0.7 ms per call).
- `npx ./blackbox-verify-0.1.0.tgz pack.json`, run on 2026-10-21 from an empty directory with the tarball of that day and the PASS run's pack (npx fetched `@noble/curves` and `@noble/hashes` from npm): PASS, exit 0; the same pack with one hex digit of step 7's `resultHash` changed: `FAIL at step 7: Receipt contents were changed`, exit 1. The current tarball pins `no-secrets-read/v2` by default, so that pack now needs `--expect-policy no-secrets-read/v1` to PASS (`test/verify-bin.test.ts` runs both from the tarball; the npx run itself has not been repeated).
- Browser, second pass (2026-10-21, headless Chrome at 375 px against `next start` on a real recorded session): `/recorder`, `/verify` (empty, FAIL sample, one byte flipped) and the step drawer on `/` and `/recorder` have no horizontal overflow; screenshots in the team's notes folder.
